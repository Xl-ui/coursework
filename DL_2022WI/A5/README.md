# Assignment 5: Transformers

本作业从基础组件开始实现 Transformer，并在两位数加减法序列任务上进行训练和验证。

## 完成内容

- 实现 Scaled Dot-Product Attention 和 Multi-Head Attention。
- 实现 Layer Normalization、Feed-Forward Block 和因果掩码。
- 实现 Transformer Encoder、Decoder 和位置编码。
- 构建加减法序列数据集及训练流程。
- 保存训练日志、模型参数和 Transformer 学习笔记。

## 主要文件

- `Transformers.ipynb`：完整实验过程与结果。
- `transformers.py`：Transformer 各组件的实现。
- `two_digit_op.json`：实验数据。
- `transformer.pt`：训练后的模型参数。
- `transformers_notes.ipynb`：学习笔记。
