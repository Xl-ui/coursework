# Assignment 3: Fully Connected and Convolutional Networks

本作业实现并训练全连接神经网络和卷积神经网络。

## 完成内容

- 实现全连接层、卷积层和池化层的前向与反向传播。
- 实现不同参数初始化方法和优化算法。
- 实现 Batch Normalization、Spatial Batch Normalization 和 Dropout。
- 构建并训练全连接网络与深层卷积网络。
- 在 CIFAR-10 数据集上进行模型训练和验证。

## 主要文件

- `fully_connected_networks.ipynb`：全连接网络实验与结果。
- `fully_connected_networks.py`：全连接网络及相关功能实现。
- `convolutional_networks.ipynb`：卷积神经网络实验与结果。
- `convolutional_networks.py`：卷积网络、归一化及初始化方法实现。
- `eecs598/`：课程提供的辅助代码。
